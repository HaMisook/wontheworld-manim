# 원, 더 월드 · 천상계 — Manim 영상 제작 실습

중학교 「원의 성질」 게임 기반 학습 플랫폼 **[원, 더 월드](https://wontheworld.netlify.app)** 의
코딩·영상 제작 실습(천상계) 교재입니다. 로드맵의 도시 10곳에서 게임으로 배운 원의 성질을,
학생이 직접 [Manim](https://www.manim.community/) 애니메이션(말없는 증명 영상)으로 만들어 봅니다.

## 사용 방법

1. 아래 표에서 차시를 골라 **Colab에서 열기**를 누릅니다.
2. 맨 위 설치 셀을 실행하고(약 2분), **[런타임] → [세션 다시 시작]** 을 누릅니다.
3. '2단계: 준비 확인' 셀부터 차례로 실행합니다.
